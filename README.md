# 高配当・優良株スクリーナー

「配当5%前後・大型株・財務良好・減配しにくい」を100点で判定する、Mac・iPad・iPhone対応のStreamlitアプリです。

## 判定

- 配当魅力度：30点
- 財務健全性：35点
- 配当継続力：35点
- A：80点以上・必須6条件通過・警告なし
- B：65点以上を基本とする安定候補
- C：要確認

異常高利回り、配当性向90%超、最終赤字、FCF赤字、5年で複数回の減配、自己資本比率20%未満を警告します。

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Community Cloudでは、このフォルダの中身をGitHubリポジトリへアップロードし、Main file pathに `app.py` を指定します。

## データ

1. 説明用サンプル：動作確認用の架空データ
2. CSV：ひな形をダウンロードして読み込み
3. オンライン取得：同梱した大型株候補から選択し、Yahoo Financeを通じて取得

無料データには欠損・遅延・取得制限があります。とくに配当予想と財務数値は、会社の決算短信・適時開示・有価証券報告書で再確認してください。

## 注意

- 金融、保険、証券、商社、REITは財務構造が異なるため、同業種比較が必要です。
- 配当利回りは株価下落だけで上昇する場合があります。
- 本アプリは調査補助であり、売買推奨や将来利益の保証ではありません。
